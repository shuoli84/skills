# macOS 拼音学习数据修复

## 结论与适用条件

特定英文输入异常可能由用户学习词库与学习模型触发。一次原生文本框复现中，输入 `dockerfil` 后，系统拼音返回了三个字符的 `do `，同时给出越界选区 `{10, 0}`。清理含英文字母的学习词条、重置用户学习模型并真正重启拼音进程后，输入与上屏恢复正常。

该修复作用于本机个性化数据。证据支持旧数据与异常存在因果关系，具体损坏记录及苹果内部缺陷仍需进一步定位。每台机器都应先复现并验证，清理数量与范围由实际词库决定。

## 简要排查过程

1. 对比问题词、较短前缀、相近长度的其他英文词，并跨应用复测。
2. 检查输入法设置和进程。仅关闭纠错、普通重启、只删一条可疑词条可能无效。
3. 用原生文本框观察输入法返回值，检查每次组合文本与选区的 UTF-16 长度。
4. 对照旧数据和干净学习数据。恢复旧数据又复现、替换数据后正常，才支持数据修复。
5. 缩小清理范围，验证中文、英文、连续输入、最终上屏和进程重启后的表现。

两个容易误判的点：

- 自动化先输入 `ni`，确认真正出现中文候选或 `setMarkedText` 回调。模拟按键直接插入英文字母时，测试无效。必要时用前台 AppKit 文本框向自身 `NSTextInputContext.handleEvent` 传入键码事件，遵循当前工具的授权要求并复用已有授权。
- 普通 `SIGTERM` 曾被 `SCIM_Extension` 忽略。用旧 PID 消失及新进程启动确认重启生效。

## 通用数据位置

从当前用户目录获取路径，先核对当前系统的文件与格式。

| 数据 | 用户目录下的路径 |
|---|---|
| 自动学习词库 | `Library/Dictionaries/DynamicPhraseLexicon_zh_Hans.db` |
| 用户学习模型 | `Library/Containers/com.apple.inputmethod.SCIM/Data/Library/LanguageModeling/zh_Hans-dynamic.lm` |
| 行为配置 | `Library/Preferences/com.apple.inputmethod.CoreChineseEngineFramework.plist` |

词库为 SQLite，已验证的 `Words` 表中 `Reading`、`Surface` 是 UTF-16LE BLOB。模型的 `.dat` 文件按不透明数据处理。系统设置里的“自定义短语”单独管理手动添加的条目。

## 在其他机器复用

在用户要求修复、症状吻合时执行。仅询问原因或整理文档时，完成分析和说明即可。

1. 在会影响学习数据的测试前，创建权限为 `0700` 的备份目录，保存原词库、整个模型目录和当轮实际偏好。SQLite 使用备份 API 或包含日志文件的一致性快照，核对 `-wal`、`-shm`、`-journal`；复制模型时保持写入静止。
2. 用附带脚本检查备份并制备候选词库。默认只预览；`--list` 可查看候选词条，`--ids` 可指定已定位的记录。`--latin` 筛选词条内容含 ASCII 英文字母的记录，是否采用此范围取决于对照结果。

以下命令以本 Skill 目录为工作目录，`BACKUP_DIR` 指向本轮备份目录，`original.db` 是已完成一致性检查的词库快照。

```bash
python3 scripts/prepare_lexicon.py --source "$BACKUP_DIR/original.db"
python3 scripts/prepare_lexicon.py --source "$BACKUP_DIR/original.db" \
  --latin --output "$BACKUP_DIR/repaired.db" \
  --removed "$BACKUP_DIR/removed.json"
```

3. 结束组合输入，确认当前用户的输入法进程身份。控制写入后原子替换候选词库，将旧模型目录移入备份隔离区，让系统重新生成学习数据。如果短暂暂停进程，使用 `try/finally` 保证恢复或终止。
4. 文件准备完成后终止旧进程，必要时使用 `SIGKILL`。确认新进程加载本次数据，再复测。原始备份应为独立副本并记录校验值，活跃进程可能继续写入被重命名文件的 inode。
5. 检查数据库完整性、保留词条集合，以及组合输入和上屏结果。中途出现越界选区也算失败。验证连续输入和重启后的表现，恢复临时改过的偏好与输入源。
6. 无改善时保留实验文件，停止输入法写入，恢复原词库与整个模型快照后重启。若只有特定应用异常，转向应用兼容性排查。

交付时说明实际清理范围、历史学习模型被重置的影响、验证范围和回滚位置。分享本 Skill、脚本及脱敏结论，个人词库与模型备份留在本机。
